# 交互体验能力项前置速查

本文件只做产品类别映射，执行顺序和检查范围见 [交互规约](PRODUCT_INTERACTION_RULES.md)。

## 意图命中表

| 用户意图/项目线索 | 优先风格 | 首先关注 |
|---|---|---|
| 生活服务、消费、个人效率、移动端 | 消费者工具与生活服务 | 单一主任务、低学习成本、即时反馈 |
| 团队协作、审批、权限、CRM、项目管理 | B 端 SaaS 与协作工作台 | 对象、角色、批量操作、可追溯 |
| CAD、IDE、设计、科研、专业编辑 | 专业软件与复杂生产工具 | 工作区、快捷效率、撤销恢复、领域术语 |
| 监控、报表、查询、发布、运维、开发平台 | 数据分析、开发者工具与后台控制台 | 状态可见、数据口径、日志、回滚 |
| 医疗、保险、银行、政务、审计、合规 | 专业服务、医疗、金融与政务 | 可信、风险、证明、权限、进度 |
| 发帖、写作、评论、社区、内容管理 | 内容、社区与创作平台 | 内容优先、发布状态、关系与治理 |
| 关卡、任务、角色、战斗、沉浸体验 | 游戏与沉浸式体验 | 规则学习、即时反馈、恢复点 |
| 问答、Copilot、Agent、自动执行、工具调用 | AI 助手、智能代理与对话式产品 | 不确定性、授权、执行范围、过程状态 |

## 类别组合

主类提供界面骨架，次类补充风险、权限或数据密度约束。AI 是行为特征，可叠加在业务类别之上；类别标签不能代替项目上下文。无法命中时使用 P3–P6 中适用的通用原则，不推定品牌、用户画像或完整产品流程。

从 [设计语言](产品大类设计语言与规范.md) 读取所选类别；专业原则见 [P3–P6](产品经理交互体验能力项_P3-P6.md)。本表不另设确认或验收清单。
