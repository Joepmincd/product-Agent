# 参考图库

本文件用于做图前选版式。先匹配信息关系，再替换为用户提供的真实内容。

## 如何使用

按信息关系选择参考图，按任务范围替换内容；示例文件位于本 Skill 的 `assets/examples/`，相对于本 reference 是 `../assets/examples/`。坐标与容量按 [模板布局](template-first-workflow.md)，字体与可读性按 [视觉样式](visual-style-constraints.md)。下面提示词只是调用示例，不增加共享工作流以外的确认或强制输出要求。

## 示例提示词

### 入口收敛图

```text
使用 $product-team-diagrams 生成一张 16:9 入口收敛图。
已知入口包括：[入口及能力列表]。
升级后统一入口是：[统一入口名称]。
右侧按用户场景表达：[场景列表]。
要求：不要补充未给出的入口；使用三栏布局；导出 SVG 和 PNG；检查文字不重叠。
```

### 上线时间线

```text
使用 $product-team-diagrams 把这份计划做成 16:9 时间线。
阶段：[阶段列表]。
每阶段需要展示：重点动作 + 产出。
要求：不自行承诺日期；没有日期时用“阶段一/二/三”；输出后做渲染检查。
```

### 运营规范矩阵

```text
使用 $product-team-diagrams 把运营规则做成矩阵图。
资源类型：[推送、Banner、活动页等]。
维度：[适合场景、文案重点、跳转要求、复盘指标]。
要求：优先表格，不画复杂连线；每格不超过两行。
```

### 严格对齐步骤流

```text
使用 $product-team-diagrams 生成一张横向步骤流图。
步骤：[步骤名称、编号、短说明]。
要求：按模板布局定义共享坐标和独立连接通道，统一同类元素的基线，连线避开正文。
```

容量与具体坐标要求见模板布局；步骤数量由真实路径决定。

### 协作边界矩阵

```text
使用 $product-team-diagrams 生成一张协作边界矩阵。
责任方：[业务方、小贴心、共同确认等]。
协作阶段：[能力定义、接入实现、上线运营等]。
每个责任方在每个阶段的职责：[职责清单]。
要求：列头与表格列宽精确对齐；不要使用漂浮按钮式列头；正文 15px 以上；每格最多 2 行；背景轻、线条轻。
```

### 居中图标网格

```text
使用 $product-team-diagrams 生成一张图标/指标卡片网格。
卡片项：[名称、图标/编号、短说明]。
要求：每张卡等宽等高；图标、标题、短说明水平居中；内容整体垂直居中；短说明最多 2 行，超过则缩短文案或改成左对齐文本卡。
```

### 多方协作泳道

```text
使用 $product-team-diagrams 生成一张多方协作泳道图。
角色：[角色列表]。
阶段：[阶段列表]。
每个角色在每阶段的动作：[动作清单]。
要求：角色在纵轴、阶段在横轴；如果动作跨角色，画少量箭头；避免箭头交叉。
```

### 优先级四象限

```text
使用 $product-team-diagrams 生成一张优先级四象限。
横轴：[成本/复杂度/投入]，纵轴：[价值/影响/紧急度]。
事项及判断依据：[事项列表]。
要求：只有定性判断时不要写具体分值；每个象限给一句处理建议。
```

### 分层架构图

```text
使用 $product-team-diagrams 生成一张分层架构图。
层级：[入口层、场景层、能力层、数据/权限层等]。
每层包含：[模块或能力]。
要求：从用户看得见的层往底层排；每层芯片不超过 4 个；不补未确认的系统。
```

### 指标漏斗

```text
使用 $product-team-diagrams 生成一张指标漏斗图。
链路：[曝光、点击、进入、使用、留存等]。
真实数据：[如果有，逐项提供]。
要求：没有真实数据时只写“待补数据/指标口径”，不要编造转化率。
```
