# 视觉样式约束

本文件维护 SVG/PNG 汇报图的视觉默认值和渲染检查。用户指定设计、已有规范及目标画布优先；几何坐标、容量和连线路由统一见 [模板布局](template-first-workflow.md)，不在本文件重复定义。

## 基础画布

- 默认 16:9：`1200 x 675`。
- 页面安全边距：左右 64-80px，上 48-72px，下 48-64px。
- 内容主区域使用 8pt 网格：横向位置、卡片宽高、内边距尽量使用 8 的倍数。
- 不让核心内容贴近画布边缘；任何文字到最近边框至少 16px。
- 页面顶部标题区高度控制在 80-112px；不要让标题太小，也不要占掉主体空间。

## 字体层级

统一使用系统中文字体栈：

```css
font-family: Arial, "PingFang SC", "Microsoft YaHei", sans-serif;
```

推荐字号：

| 层级 | 字号 | 字重 | 用途 |
|---|---:|---:|---|
| 页面标题 | 28-34px | 700 | 图的主结论，不超过一行 |
| 页面副标题 | 16-18px | 400 | 解释图的上下文 |
| 分组标题 | 20-24px | 700 | 当前/升级后/阶段等 |
| 卡片标题 | 18-21px | 700 | 模块名、阶段名 |
| 正文 | 14-17px | 400 | 卡片内说明 |
| 辅助标签 | 13-15px | 400/600 | 月份、状态、备注 |

约束：

- 同一层级字号必须一致，不要每个卡片手调。
- 正文最小不要低于 13px；用于投屏或截图分享时，正文建议 15px 以上。
- 16:9 汇报图默认正文使用 15-17px；如果内容放不下，先删减文案、换模板或拆图，不通过缩小字号解决。
- 中文长句主动断行，避免一行塞到底。
- 标题、副标题、卡片标题的基线要对齐，不要出现“看起来漂浮”的标签。

## 内容去重与换行策略

- 同一信息在同一张图里只出现一次。时间、阶段、角色、状态如果已经在轴线/标签上出现，卡片内不要重复。
- 时间线图在“轴上月份”和“卡片内月份胶囊”之间二选一：
  - 强调时间节奏时，月份放在线上节点，卡片内只写阶段标题。
  - 强调阶段卡片时，月份放卡片内，线上节点不再写月份。
- 避免为了视觉对齐强行断开短句。短句能一行显示就保持一行。
- 换行只在语义边界处发生，例如“动作 / 结果”“对象 / 说明”“主语 / 补充条件”。
- 不要把强关联词拆开，例如“语音、桌面全局入口”“Agent 入口下线”“灰度开放”。
- 列表项的第一行和续行要有固定缩进；续行不应看起来像新的 bullet。
- 卡片标题不和列表项重复表达。例如标题写“能力升级与灰度开放”，列表里不要再写“能力升级”作为单独项，改写成具体动作。
- 底部总结条只总结全局节奏，不重复逐月标题。

## 卡片与分组

- 卡片分组与几何对齐使用模板布局；视觉层级一致，不用装饰差异暗示不存在的语义。
- 卡片内边距：横向 24-28px，纵向 20-24px。
- 卡片圆角：默认 8px；同一页不要混用 6/8/12 等多个圆角。
- 卡片边框：默认 1.5-2px；不要用过亮边框抢正文。
- 卡片背景可以轻微染色，但透明度要低，避免整页变成色块展示。
- 卡片内列表的 bullet、文字起点和换行缩进必须成一条竖线。
- 独有标签只有在表达真实差异时才保留；全局总结放在图外，不为视觉对称编造其他卡片的内容。

## 文本对齐

短标签、数字、图标和流程节点通常居中，长说明、列表与矩阵正文通常左对齐。使用同一内容类型的一致策略，按信息层级调整，不将居中当作所有图表的强制布局。

SVG 单行文字居中时组合 `text-anchor="middle"` 和适用的 `dominant-baseline`，并通过实际字体渲染检查光学偏移；多行文字使用一致的 x 和行距。卡片、连线、时间线和矩阵的坐标关系见模板布局。

## 矩阵与边界图专项约束

- 列头、短标签、角色名默认居中；单元格里超过一行的职责说明可以左对齐。
- 行头必须清楚标出维度，例如“能力定义、接入实现、上线运营”；不要让第一列既像标题又像正文。
- 表格线使用浅色 1px，外框不超过 1.5px；避免大外框 + 粗内线的双重噪声。
- 单元格正文建议 15-16px、行高约 1.45；容量依模板和画布判断，不用小字号塞满信息。
- 表格背景以白色或极浅底色为主；不要让整块灰色背景压低对比度。
- 强调色只用于列头或少量标签，不要让每个单元格都带高饱和边框。
- 总结句要放在表格下方并与表格主区域对齐，不能漂浮在外框内部的随机位置。

## 色彩与线条

- 单页主色不超过 1 个，辅助色不超过 3 个。
- 颜色用于表达分类、阶段或状态，不用于装饰性随机分配。
- 推荐中性色：
  - 背景：`#F7F8FB`
  - 主文字：`#20242C`
  - 次文字：`#667085`
  - 边框：`#D0D5DD`
  - 连接线：`#98A2B3`
- 强调色建议降低饱和度或只用于标题/节点，不要整张卡片高饱和边框。
- 连接线 2.5-4px；时间线可 4-6px。节点尺寸必须与线宽匹配。
- 阴影慎用；业务同步图优先用边框、留白和色块表达层级。
- 背景用于承托内容，不是视觉主角。若背景色和表格/卡片太接近，必须提高内容区对比。
- 避免“灰底 + 大白框 + 细小文字”的低对比组合；业务图优先保证文字和结构清晰。

## 图标与指标的层级

图标容器推荐 48-72px，图标与标题间距约 20-28px，标题与说明间距约 12-16px；实际尺寸依据画布和阅读距离调整。指标卡中数字是主信息，单位和说明降一级。标题、数字、说明的几何关系使用模板布局，避免同一组混用不同对齐逻辑。

## 渲染检查

用可用工具预览完整画布及实际插入文档/投屏的尺寸；只有需要 PNG 时才导出 PNG。检查以下视觉问题，并结合模板布局核对几何关系：

- 信息层级是否清楚，标题和重点是否先被看到；不要为凑结构强加副标题或底部总结。
- 文字是否裁切、重叠、贴边、过小；语义换行是否自然，列表续行是否稳定。
- 字体和同级字号是否一致，正文对比度是否足够，颜色是否表达分类或状态。
- 边框、背景、阴影是否抢过正文；矩阵线条是否轻且清楚。
- 同一信息是否在轴线、卡片和总结中重复，独有标签是否确有语义。
- 卡片、文本、分支标签与连接线是否互相遮挡，最终使用尺寸是否仍可读。

没有渲染工具时可以检查 SVG 结构和坐标，但不能声称视觉检查通过；实际验证范围和限制按主 Skill 交付。
