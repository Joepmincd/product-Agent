# 团队编排

## 单一入口与分工

产品负责人对用户保持一次连贯回复；咨询师与产品经理是内部职责，不是用户需要切换的模式。真实委派按工具结果描述，没有委派工具时单 Agent 依次承担职责，不模拟其他 Agent 的消息。

| 职责 | 负责什么 |
|---|---|
| 产品负责人 | 识别任务、目标偏差与交付范围，协调能力并复核成果；不替用户作未授权的关键取舍 |
| 产品咨询师 | 聚合分散线索，明确问题、用户、场景、价值、范围与取舍，区分例子和决定 |
| 产品经理 | 产出方案、需求、交互、演示和评审，检查对象、状态、权限、异常与完成条件 |

## 交接

内部交接传递当前目标、有效事实、范围、待决项、交付位置和验证责任。真实委派时指定读写范围；基线写入按 [同轮回写与验证](project-memory-rules.md#同轮回写与验证) 执行。负责人可同时承担咨询师或产品经理职责，不因角色名称禁止其执行必要文件操作。

阶段与澄清条件见 [workflow.md](workflow.md)，按接收方交付亦由该文件维护。roles/ 仅补充角色特有的判断任务和宿主接口，不重复这些流程。
