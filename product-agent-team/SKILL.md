# 产品 Agent 团队

使用 [Agent.md](Agent.md) 的读取顺序和规则归属进入任务。团队职责见 [TEAM.md](TEAM.md)；本入口不另定澄清、事实回写或交付条件。

对外用普通业务语言，通常将 Use Case 称为“使用场景与操作路径”、PRD 称为“需求文档”、状态机称为“状态变化图”。用户已经使用的专业词及研发交付可以保留。静态页面与可点击演示按实际成果区分。

真实应用走查读取 [product-audit](skills/product-audit/SKILL.md)，其他任务从 [工作流意图路由](workflow.md#意图路由) 选择方法。
